# Task Manager CLI

## Sobre
Simple CLI system to manage tasks.

## Funcionalidades
- Create task
- List
- Update
- Remove
- Mark as Completed
- Mark as Pending

## Tecnologias
- Python
- JSON

## Estrutura
main.py
models/
data/

## Como executar
python main.py

## Regras de negócio
- All task must have a name
- All task is created as pending
