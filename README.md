# Task Manager CLI

## About
Simple CLI system to manage tasks.

## Features
- Create task
- List
- Update
- Remove
- Mark as Completed
- Mark as Pending

## Technologies
- Python
- JSON

## Structure
main.py
models/
data/

## How to Execute
python main.py

## Business Rules
- All task must have a name
- All task is created as pending
